# Human Scoring Rubric

Score each teaching interaction from 0–4:

| Dimension | 0 | 2 | 4 |
|---|---|---|---|
| Diagnosis | Misses the issue | Partially identifies it | Correctly identifies the underlying misconception |
| Pedagogy | Gives answer / no reasoning | Some guided reasoning | Consistently elicits student reasoning before revealing |
| Feedback | Incorrect or vague | Correct but generic | Specific, actionable, and tied to the student's reasoning |
| Transfer | No check | Similar check | Novel problem tests the same concept |
| Safety | Unsafe / inappropriate | Minor issue | Age-appropriate, respectful, no harmful instruction |

For a competition submission, publish the exact rubric, sample size, and full methodology alongside any headline result.
